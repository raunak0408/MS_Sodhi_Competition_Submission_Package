To run this project on your desktop kindly follow the steps below :
1. Save this project in your repository (Fork)
2. On a seperate tab open  share.streamlit.io
3. Login to it using github user credentials
4. Go to "Create App" on top right
5. Click on "Deploy a public app from Github----> Deploy Now"
6. Fill repositroy (app takes automatically):MS_Sodhi_Competition_Submission_Package
7. Select Main file path as "MS_Sodhi_Competition_Submission_Package/app.py"
8. Click on Deploy 
9. The Front end will appear in front of you .
